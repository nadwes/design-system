Usage Guidelines
Do
  • Use semantic tokens (e.g., brand/primary-colors/regular) in components
  • Test all color combinations for WCAG AA compliance (4.5:1 for text, 3:1 for UI elements)
  • Use sport-specific colors only when a sport context is active
  • Reference primitives only from semantic tokens, never directly in components
Don't
  • Don't use primitive tokens (e.g., blue500) directly in components
  • Don't create new color values outside the token system
  • Don't use sport colors as general-purpose brand colors
  • Don't assume color alone conveys meaning — always pair with text or icons for accessibility

Headings
Use tight line heights (0.93–1.25×) for display headings. Bebas Neue and Oswald are condensed typefaces — generous line heights create awkward gaps. Single-line headings can use 1.0× or below.
Body Text
Use 1.375–1.5× for body copy. WCAG 1.4.8 recommends at least 1.5× for long-form text. The body-base token (16px / 22px) meets this at 1.375× — acceptable for short UI text. For articles or long descriptions, prefer 1.5× or higher.

Usage Guidelines
Headings
  • Use H1–H3 (Bebas Neue) for hero titles, page headers, and section names. Always uppercase.
  • Use H4, H6 (Oswald) for editorial subheadings and mixed-case titles where all-caps would be too heavy.
  • Use H5, H7 (Bebas Neue) for card titles, widget headers, and compact section labels.
  • Never use heading tokens for body copy or labels — they are not designed for reading at length.
Body Text
  • body-base (16px) is the default for all UI text, descriptions, and form fields.
  • body-s (14px) for secondary information, metadata, timestamps, and helper text.
  • body-xs (12px) for captions, legal disclaimers, and badge labels only. Do not use for running text.
  • Minimum body size for readable content is 14px. Never go below 12px for any visible text.
Labels & Buttons
  • Use the interaction token (Bebas Neue / 16px / 700 / uppercase / ls: 0.03em) for all CTA buttons and primary actions.
  • Navigation labels use Titillium Web 500 or 600 at 12–13px with letter-spacing 0.5–1px.
  • Form labels use body-s (14px / 400). Input text uses body-base (16px / 400).
Captions & Metadata
  • Use body-xs (12px) for image captions, timestamps, and supplementary metadata.
  • Pair with --text-subtle color for visual hierarchy — never use full --text at 12px.
  • Monospace font (--mono) is reserved for token names, code snippets, and technical values in documentation only.
Accessibility
  • Minimum font size for body text: 14px. Minimum for any visible text: 12px.
  • Body text line height must be at least 1.375× the font size (WCAG 1.4.8 recommends 1.5× for long-form).
  • Letter spacing on body text must remain at 0 — do not add tracking to running text as it reduces readability.
  • All-caps text (Bebas Neue headings) must not be used for body copy — it significantly reduces reading speed.
  • Text contrast must meet WCAG AA: 4.5:1 for body text, 3:1 for large text (18px+ or 14px+ bold). See Color → Accessibility for full contrast table.
✓ Do
  • Use Bebas Neue for all-caps display headings and CTAs
  • Use Titillium Web for all body copy and UI text
  • Use em-based letter-spacing for scalable tracking
  • Pair heading tokens with matching line-height tokens
  • Use --text-subtle for secondary and metadata text
✗ Don't
  • Don't use Bebas Neue for body copy or long-form text
  • Don't mix heading families within the same heading level
  • Don't use pixel letter-spacing — always use em values
  • Don't go below 12px for any visible text element
  • Don't add letter-spacing to body text (body-base, body-s, body-xs)

Responsive Typography NEW ADDITION

A controlled fluid typography approach using clamp(). Scaling is viewport-based and constrained between defined minimum and maximum values. Typographic hierarchy must remain intact across all breakpoints.

Apply responsive scaling to
  • All heading styles (heading-h1 through heading-h7)
  • body-xl (40px)
  • body-l (32px)
  • body-m-plus (28px)
  • body-m (24px)
  • body-s-plus (22px)
Do NOT scale — fixed sizes
  • body-base (16px) — accessibility baseline
  • body-s (14px) — UI text, labels
  • body-xs (12px) — captions, legal text
Fixed sizes ensure readability and accessibility compliance at all viewport widths.
